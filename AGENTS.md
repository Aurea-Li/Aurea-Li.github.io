<INSTRUCTIONS>
This repository is a Hugo static site for "Aurea-Li.github.io" using the PaperMod theme. It is a photography blog.

Quick orientation
- `hugo.toml` configures site metadata, theme selection, and params (including `customCSS`).
- `content/` holds posts and pages (main content source).
- `layouts/` contains custom Hugo templates overriding theme layouts.
- `assets/` contains custom pipeline assets (e.g., `assets/css/custom.css` used by PaperMod).
- `static/` contains static files copied as-is to the site output.
- `themes/PaperMod/` is the upstream theme.
- `public/` is the built output directory (generated by Hugo).

Common tasks
- Run the dev server: `hugo server` (rebuilds and serves locally).
- Build the site: `hugo` (writes to `public/`).

Notes
- Prefer editing templates in `layouts/` and styles in `assets/css/` for theme overrides.
- Avoid manual edits in `public/` since it is generated.
</INSTRUCTIONS>
